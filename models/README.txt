3D models for the food go in this folder.

One file per dish, in .glb format, named exactly like this:

  chicken-wrap.glb
  chicken-burger.glb
  paneer-sandwich.glb
  corn-sandwich.glb
  chocolate-truffle.glb
  red-velvet.glb
  blueberry-cheesecake.glb

Nothing else needs changing. When a dish has a .glb here, its plate turns into a
3D model you can drag round. When it does not, the site shows the photo instead.

Keep each file under about 5 MB so it loads quickly on a phone.
The 3D view needs the site to be served (Vercel, or a local server). It does not
work when index.html is opened by double-clicking.
